# Taskrail support

Taskrail is maintained in the public GitHub repository:

- Usage questions and reproducible bugs: [open a GitHub issue](https://github.com/Yuxin-Qiao/Taskrail/issues/new/choose).
- General project discussion: [GitHub Discussions](https://github.com/Yuxin-Qiao/Taskrail/discussions).
- Security vulnerabilities: use the repository's [private security advisory form](https://github.com/Yuxin-Qiao/Taskrail/security/advisories/new), or follow [SECURITY.md](../SECURITY.md) if that form is unavailable.

Please include the Taskrail version, operating system, the smallest safe
reproduction, and the relevant command or tool name. Remove credentials,
tokens, private automation definitions, private repository content, and raw
logs that contain sensitive data before submitting a report. Support is
provided through the repository; Taskrail does not currently promise a paid
support response time or operate a separate hosted support portal.
