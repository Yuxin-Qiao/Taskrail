# Integration icon sources

These files are upstream brand assets used to identify the tools that Taskrail
connects to in the README topology graphic. The upstream projects retain their
respective copyright and trademark rights.

- `mole-mark.png` — [tw93/Mole](https://github.com/tw93/Mole), from the official [Mole site](https://mole.tw93.fun/img/mole-mark.png).
- `homebrew.svg` — [Homebrew/brew](https://github.com/Homebrew/brew), from [brew.sh](https://brew.sh/assets/img/homebrew.svg).
- `restic.png` — [restic/restic](https://github.com/restic/restic), from [`doc/logo/logo.png`](https://github.com/restic/restic/blob/master/doc/logo/logo.png).
- `rclone.svg` — [rclone/rclone](https://github.com/rclone/rclone), from [`graphics/logo/svg/logo_symbol_color.svg`](https://github.com/rclone/rclone/blob/master/graphics/logo/svg/logo_symbol_color.svg).
