# Contributor Covenant Code of Conduct

Taskrail is a welcoming project. Contributors and maintainers are expected to
be respectful, constructive, and inclusive in issues, reviews, discussions,
and commits.

Unacceptable behavior includes harassment, discrimination, personal attacks,
publishing private information, and deliberately disruptive conduct. Project
maintainers may remove comments, close discussions, or restrict participation
when needed to keep the project safe and productive.

Report conduct concerns privately to the maintainer listed in the repository
security policy. Please do not include credentials, private automation
definitions, or other sensitive data in a report.
